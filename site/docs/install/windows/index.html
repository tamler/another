Another on Windows

There is no native Windows build. WSL 2 is the route to try, and we have not run it yet.

macOS Linux Windows All install options

Why not native Windows

Nothing in the project builds or tests on Windows. The planned release targets are macOS and Linux, and CI does not run on Windows. Parts of the product also assume a Unix system:

Hooks
The client hook wrapper is a /bin/sh script.
Orphan scan
Finding listening processes uses lsof or ss.
Reaping
Stopping an orphan calls kill.
Wake
The adapters drive tmux, cmux or Herdr.

Whether the mail and MCP parts compile on Windows is unknown, because no one has tried. Treat native Windows as unsupported, and if you test it, open an issue with what happened.

The WSL 2 route

WSL runs a Linux distribution on Windows, so Another should behave as it does on Linux. In an administrator PowerShell, Microsoft's install command sets up WSL 2 with Ubuntu on Windows 10 version 2004 or later and on Windows 11. Restart when it finishes.

wsl --install

Open the Ubuntu terminal and follow the Linux install page from there.

Keep everything on the Linux side

Another's state, its hooks and its MCP server all need to be where your coding client runs. Run the client inside WSL too, and start it from your project in the WSL file system.

  • A Windows-side client would look for its config and hooks in your Windows profile, not your WSL home, where another hook install writes them.
  • Keep repositories in your Linux home, such as ~/projects/shop, rather than under /mnt/c. Microsoft recommends the WSL file system when you work from a Linux command line.
  • Leave ~/.another in the default place. It holds a SQLite database, and it has not been tested on a mounted Windows drive.

What this page rests on

The list of Unix dependencies comes from Another's source and workflows. The WSL commands come from Microsoft's documentation. The Linux steps ran in a clean Ubuntu container, which is not WSL. No one has yet run Another on Windows or in WSL for this page, so a report in either direction would help. The FAQ covers other platform questions.
