Another on macOS

Command line tools, Rust, one Cargo command, and a PATH your coding client can see.

macOS Linux Windows All install options

1. Get a compiler and Rust

Another builds from source today, and there is no published release yet. Cargo needs a C toolchain to link, and Another's SQLite is compiled from bundled C source. Apple's command line tools provide it:

xcode-select --install

That opens a system dialog, and it reports an error if the tools are already installed. Then install Rust with the official installer, or skip this if rustc --version already prints 1.88 or newer:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustc --version

If rustc is not found, open a new terminal. The installer's PATH change may not apply until the console restarts.

2. Install Another

cargo install --locked --git https://github.com/tamler/another another
another --version

Allow a few minutes for the first compile. The binary lands in ~/.cargo/bin. The main install page covers source builds, updates and replacing a binary safely on macOS, which matters if you ever copy a new build over an old one.

3. Make sure your client can find it

zsh is the default macOS shell, and a working terminal does not prove your coding client sees the same PATH. An app opened from the Dock or Finder may not read your zsh configuration, so an MCP entry that says another can fail while the terminal works. Print the full path:

command -v another

If the client cannot start the server, put that absolute path in its MCP command field in place of another. Terminal-launched clients normally inherit your shell's PATH.

4. Try it without touching your setup

This runs in throwaway state. It changes no client configuration and starts no server.

(
  export ANOTHER_HOME="$(mktemp -d)"
  another init
  another agent register alice --program claude --project .
  another agent register bob --program codex --project .
  another send --from alice --to bob --subject "Hello" --body "First message." --request
  another inbox --agent bob
)

Bob's inbox should show one unread message and one open request. Then connect hooks and MCP using your real ~/.another.

When a release exists

No release has been published. The release workflow is set up to build aarch64-apple-darwin for Apple Silicon and x86_64-apple-darwin for Intel; uname -m prints arm64 or x86_64 to tell you which applies. Planned binaries are unsigned, so after verifying the checksum macOS may need the quarantine attribute removed from that binary:

xattr -d com.apple.quarantine ./another

What this page rests on

The Cargo install and the exchange above ran on Apple Silicon with Rust already present. Installing the command line tools and Rust on a clean Mac has not been run for this page; those two steps follow Apple's and Rust's own instructions. CI builds the Intel target, but no one has executed that binary.
