Another on Linux

A C compiler, a current Rust from rustup, and one Cargo command.

macOS Linux Windows All install options

1. Install a compiler, and Rust from rustup

Another needs Rust 1.88 or newer. Your distribution's package may be older: on Ubuntu 24.04, apt offered rustc 1.75 when we checked. Use rustup unless rustc --version already prints 1.88 or newer.

You also need a C compiler. Without one, the install stops with linker `cc` not found. On Debian and Ubuntu:

sudo apt-get update
sudo apt-get install -y build-essential curl git
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
. "$HOME/.cargo/env"
rustc --version

On other distributions, install their compiler package and then the same rustup command. The . "$HOME/.cargo/env" line applies rustup's PATH to the current shell; new login shells normally get it from the lines rustup added to your profile.

2. Install Another

cargo install --locked --git https://github.com/tamler/another another
another --version
command -v another

The binary lands in ~/.cargo/bin. If your coding client runs as a service or from a desktop launcher, it may have a different PATH from your terminal. Give its MCP config the absolute path that command -v another printed. The main install page covers source builds and updates.

3. Try it without touching your setup

(
  export ANOTHER_HOME="$(mktemp -d)"
  another init
  another agent register alice --program claude --project .
  another agent register bob --program codex --project .
  another send --from alice --to bob --subject "Hello" --body "First message." --request
  another inbox --agent bob
)

Bob's inbox should show one unread message and one open request. Then connect hooks and MCP using your real ~/.another.

Linux details worth knowing

Orphan scanning needs lsof or ss. another orphans uses them to find listening processes that nothing registered. Minimal images and containers may have neither. It then prints scan unavailable along with any lapsed registered resources, and a line saying no orphans were found does not mean the machine is clean. Install lsof or iproute2 if you want the scan.

Wake is optional. Waking an idle agent needs tmux, cmux or Herdr; nothing else in Another uses them.

Containers keep their own state. Each container has its own ~/.another unless you mount one. To coordinate agents in different containers or machines, see agents on two machines.

When a release exists

No release has been published. The release workflow is set up to build static musl binaries, x86_64-unknown-linux-musl and aarch64-unknown-linux-musl, which need no Rust or compiler. uname -m prints x86_64 or aarch64. Verify the checksum before you unpack one.

What this page rests on

On 5 November 2026 we ran these steps as root in a clean ubuntu:24.04 container on arm64, without sudo and with rustup in its non-interactive mode. The install failed with the linker error before build-essential and passed after it, and the exchange then produced the expected inbox. x86_64, other distributions and a full desktop session have not been run for this page. CI runs the tests on Linux.
