What shipped

On main as of 12 Nov 2026. I checked the repo that day: 0 stars, 1 fork, and no GitHub Release. If those numbers move, this page should move with them.

Install is still cargo install --locked --git https://github.com/tamler/another another with Rust 1.88 or newer. The release workflow can build macOS and static Linux binaries when a v* tag exists. None has been published.

On main

1. Local core
SQLite event log, agents, mail, requests, path holds, MCP over stdio and loopback HTTP, CLI. PR 1.
2. Hooks and the feed
Activity summary, session events, hook packs, another hook install. PR 2.
3. Resources
Shared and exclusive leases, an orphan scan, reap only after a person passes --confirm. PR 3.
4. Remote peer
Scoped bearer tokens, an audit log, GET /activity. Loopback unless you opt into a remote bind. PR 4.
5. Federation
Signed event logs, pairing, hub-and-spoke sync, cross-node mail. Requests stay on one node. PR 5.
6. Wake and release builds
another wake for tmux, cmux, and Herdr. Optional Herdr plugin. Release workflow, quickstart, contributing notes. PR 6.
7. Hosted connectors
OAuth 2.1 on another serve --auth --public-url, so ChatGPT custom connectors and Claude.ai can attach. A grant exists only after another oauth approve on the machine that holds the database. another remote up prints the URL to paste. whats_new for a one-call catch-up. The ChatGPT desktop app on the same machine uses plain stdio or loopback HTTP, with no tunnel. PR 99.
Local dashboard
another dashboard, or GET /ui on a loopback another serve. Agents, holds, mail, requests, resources, and the feed. Message bodies stay on that machine. An authenticated server does not serve it unless you ask, and then it is read-only. PR 100.
Push and enforced holds
A one-line notice after the next tool call when mail lands mid-task. Before each file edit, a hook takes a hold on that file, or stops the edit and names the holder when another agent holds it (Claude Code, Codex, Grok CLI; not Cursor, and not edits made from a shell command). Holds are checked across worktrees and clones of one repository. A launchd daemon on macOS that wakes idle Herdr agents. another stats. PR 103, PR 104, PR 105.

The project was renamed to Another in PR 8. PR 95 closed token-scope bugs (a remote token could reach outside the projects it was minted for). That fix is on main.

In progress, not merged

Nothing on this page comes from an open pull request. Work that is still in review is not described here until it is on main, because I am not going to describe it as if you can turn it on.

Later, not started here

From the spec, still out of scope for the code on main: a pre-commit hold guard, auto-reap policies, mesh federation, end-to-end mail encryption. The edit hook stops a client edit to a held file, but an edit from a shell command still gets through and nothing guards a commit. Reaping stays a human confirm on the owning machine. I would rather ship those late than pretend a hold is a lock.
