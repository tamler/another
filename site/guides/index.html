Task guides for coding agents

Pick the coordination job in front of you. Each guide covers one workflow, with the commands and where it falls short.

Choose by job

Local inbox
New to Another? Try a terminal exchange in temporary local state, with no client changes, and see what stays on your machine.
Claude Code + Codex
Two clients in one repository. Connect independently run sessions to one project inbox and send a review request.
Multiple Claude Code sessions
The same client running twice in one checkout. Give each session its own identity so their mail and holds stay apart.
MCP messaging
Connecting any MCP client. Send mail, fetch it, record a receipt and claim the work as distinct operations.
File holds
Agents editing the same tree. Let the edit hook mark each file, check overlap, and know what a shell edit gets past.
Git worktrees
An agent per worktree. See what crosses between worktrees, including holds, and what doesn't.
Hand off a task
Work that needs an owner. Open a request, claim it, complete or release it, and take over when it goes stale. Includes a recorded run where the worker acks, claims, and crashes.
Share a model server
Agents starting duplicate servers. Register one, borrow it with a lease and clean up orphans with a human check.
Wake idle agents
An agent waiting at its prompt with unread mail. Nudge its tmux pane, and learn what can go wrong.
Two machines
A laptop and a remote box. Pair nodes through a hub you host, and see what each side can read.

If it might be the wrong tool

Another connects agents you already run; it does not start or manage them. Compare it with inboxes and orchestrators or read when not to use it before you install.
