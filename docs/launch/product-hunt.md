Another is for the space between coding-agent sessions: send a review request, see recent activity, or borrow a running resource. It does not replace your agent client or run a team.

The local flow works through a Rust CLI and MCP server. Hooks announce waiting mail at session start and on prompts. The first-run guide includes a shell demo and a dry-run of user-global hook changes.

Free and open source under Apache-2.0, with no product telemetry or paid tier. Optional federation uses a self-hosted hub that can read relayed mail; path holds remain advisory.
